개인정보처리방침

최종 갱신: 2026년 9월 29일

1. 개요

property-watch(이하 "이 도구")는 제작자 본인만 사용하는 개인용 프로그램입니다. 외부 이용자에게 서비스를 제공하지 않으며, 제작자 본인 외의 개인정보를 수집하지 않습니다.

2. 접근하는 정보

이 도구는 사용자가 직접 허용한 범위에서만 구글 계정에 접근합니다.

  • 구글 캘린더 — 사용자가 지정한 캘린더에 일정을 생성합니다
  • 구글 Tasks — 사용자의 할 일 목록에 항목을 추가합니다

읽기는 중복 등록을 막기 위한 기존 항목 확인에만 사용합니다.

3. 저장 위치

인증 토큰은 사용자 본인의 컴퓨터에 있는 macOS 키체인에만 저장됩니다. 이 도구는 서버를 운영하지 않으며, 어떤 정보도 제작자의 컴퓨터 밖으로 전송하지 않습니다.

4. 제3자 제공

수집하거나 접근한 정보를 제3자에게 제공하거나 판매하지 않습니다. 광고, 분석, 추적 도구를 사용하지 않습니다.

5. 보관 기간

사용자가 구글 계정 설정에서 이 앱의 접근 권한을 해제하면 토큰은 즉시 무효가 됩니다. 로컬에 저장된 토큰은 키체인에서 직접 삭제할 수 있습니다.

6. 문의

이 도구에 관한 문의는 GitHub 저장소의 이슈로 받습니다.
